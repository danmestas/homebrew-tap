# danmestas/homebrew-tap

Homebrew tap for [danmestas](https://github.com/danmestas) binaries.

## Install

```bash
brew install danmestas/tap/darken
```

## Formulae

- `darken` — Darkish Factory orchestration substrate CLI ([source](https://github.com/danmestas/darkish-factory))

The `Formula/darken.rb` file is auto-generated by goreleaser on each release of `darkish-factory`. Don't edit by hand.
